# 基本設計書

## 1. はじめに

### 関連文書

関連する文書を記載する

### 用語定義

開発対象特有の用語を記載する。

## 2. 概要説明

開発対象の役割や意義を記述する。

## 3. 要件

### 要件一覧

要件1つに対して、以下の項目を記載する。企画書等から要件を起こす。

- ID
- 要件名
- 要件
- 背景
- 備考
- 実現時期

### 補足

要件の補足がある場合、ここに記載する。

## 4. ユースケース

要件と対応するユースケースを記載する。
ユースケース1つに対して、以下の項目を記載する。

- ID
- 目的
- ペルソナ
- ワークフロー
- 対応する要件

## 5. 概念図モデル

開発対象に関連する情報や役割をクラス図等で記載する。

## 6. 非機能要件

非機能要件を記載する。要件1つに対して、以下の項目を記載する。

- ID
- 実行者: 特定の誰かが
- 状況: 特定の状況・制約のもとで
- 動作: 何かをすると
- 対象: システムが
- 応答: どうする（どうなる）
- 測定: 測定可能な数値目標

## 7. その他・注意事項

補足事項や注意事項があれば記載する。
